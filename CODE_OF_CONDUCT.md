# Code of Conduct

Headroom follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
In short: be kind, assume good intent, and keep discussions about the work.

If someone's behavior bothers you, contact the maintainer,
[Marvin Splitt](https://github.com/marvin-splitt), privately. Reports are handled confidentially.
